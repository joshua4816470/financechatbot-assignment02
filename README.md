# 🤖 AI Personal Financial Advisor (FinBot)

This project presents an AI-powered Personal Financial Advisor built using a fine-tuned **Qwen 2.5 1.5B Large Language Model (LLM)** with **LoRA adapters**, combined with a **rule-based financial engine** and **real-time Yahoo Finance data**.

The system provides personalised financial planning, budgeting guidance, and investment recommendations through an interactive web-based chatbot.

---

## 🚀 Features

- 🔹 Fine-tuned LLM (Qwen 2.5 1.5B + LoRA)
- 🔹 Guided financial dialogue system (step-by-step data collection)
- 🔹 Rule-based financial calculations (accurate & transparent)
- 🔹 Emergency fund & investment planning
- 🔹 Real-time stock data integration (Yahoo Finance)
- 🔹 Personalised investment recommendations
- 🔹 Flask-based web application frontend

---

## 🧠 System Architecture

The system follows a **hybrid design**:

1. **LLM (Qwen + LoRA)**  
   - Handles natural language understanding and response generation  
   - Supports follow-up reasoning and conversational interaction  

2. **Rule-Based Engine**  
   - Performs financial calculations (surplus, savings rate, timelines)  
   - Ensures accuracy and consistency  

3. **Yahoo Finance Integration**  
   - Fetches real-time stock prices and market data  
   - Enhances investment decision-making
